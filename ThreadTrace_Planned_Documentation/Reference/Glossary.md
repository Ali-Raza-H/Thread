# Glossary

| Term | Definition |
| --- | --- |
| Project | A registered Python codebase and its configuration. |
| Scan | A persisted static-analysis snapshot. |
| Run | An execution of target project code. |
| Trace | Recorded events produced by an instrumented run. |
| Ignore | Exclude selected code from tracing or presentation without intentionally changing execution. |
| Disable | Replace or prevent selected behaviour during an experiment. |
| Override | Substitute a specified value or input. |
| Live edit | Modify selected runtime state while execution is paused. |
| Patch | Temporarily replace code for an experiment. |
| Edit source | Modify the actual source file on disk. |
| Isolate | Execute a selected function or class in a controlled harness. |
| Experiment | A saved configuration of controlled behavioural changes. |
| Investigation | A saved collection of findings, traces, notes, and related analysis. |
| Entry point | A mechanism through which execution can enter application logic. |
| Instrumentation | Mechanisms used to observe or intercept target execution. |
